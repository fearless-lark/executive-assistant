# Чекліст безпеки

Видай користувачу розділ, що відповідає його типу плану, і спільну частину. Назви пунктів меню змінюються. Якщо пункт не знайдено, порадь пошук у налаштуваннях за ключовим словом.

## 1. Корпоративний план (Team, Enterprise, Business, Edu з договором обробки даних)

1. Корпоративні дані обробляються лише в корпоративному акаунті. Особистий акаунт для роботи з поштою компанії не використовується.
2. Адміністратор увімкнув скіли, потрібні конектори і, за потреби, хмарні заплановані задачі.
3. Права на запис у конекторах увімкнені лише там, де вони потрібні: чернетки пошти, документи у власному сховищі.
4. Підтвердження дій у конекторах лишаються ввімкненими. Надсилання з Outlook на Claude не можна поставити на «завжди дозволяти», і це правильна поведінка.
5. Якщо організація забороняє скіли користувачів, профіль живе в документі «Exec profile» з доступом лише для вас.

## 2. Особистий план (Free, Pro, Max, Plus, Pro)

1. Вимкніть використання ваших розмов для навчання моделей. Claude: **Settings → Privacy → Help improve Claude**. ChatGPT: **Settings → Data controls → Improve the model for everyone**.
2. Не ставте 👍 і 👎 у робочих чатах. Оцінка надсилає розмову постачальнику на перегляд.
3. Не створюйте публічних посилань на робочі чати.
4. Не встановлюйте в робочий браузер розширень, які «читають сторінку» для інших сервісів ШІ.
5. Не завантажуйте документи з грифом конфіденційності, персональні дані працівників і банківські дані без потреби. Асистент попросить підтвердження перед такими документами.
6. Плануйте перехід на корпоративний план, якщо асистент працює з даними компанії регулярно.

## 3. Спільне для всіх

1. Жодна регулярна задача не надсилає листів і не змінює зовнішніх систем. Результат: чат, push, чернетки.
2. Для роботи асистента в браузері використовуйте окремий профіль Chrome без банківських входів і особистих акаунтів.
3. Встановлюйте скіли лише з джерел, яким довіряєте. Перед встановленням перегляньте текст скіла.
4. Двофакторна автентифікація на акаунті Claude чи ChatGPT і на пошті.
5. Раз на квартал перегляньте підключені конектори і відключіть зайві.
6. Підозрілі листи, які асистент позначив блоком «⚠️ Підозрілий вміст», пересилайте в службу безпеки за звичною процедурою компанії.

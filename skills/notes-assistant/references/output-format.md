# Формат відповідей асистента нотаток

Це розмовний скіл. Блок «Головне» потрібен лише тоді, коли скіл викликано із запланованої задачі. У розмові відповідай коротко, у форматі режиму.

## Формати за режимом

| Режим | Формат |
|---|---|
| Спільний розбір | картка нотатки з `references/method.md`, розділ 1; у кінці підсумок розбору |
| Нотатка в дію | що створено · що чекає підтвердження · новий статус у заголовку |
| Нова нотатка | назва · папка · заголовок зі статусом «нова»; одне речення |
| Пошук думок | хронологія · підсумок зміни думки з упевненістю · пропозиція |
| Звірка виконання | таблиця «ідея · оцінка · доказ · пропозиція» |

## Підсумок спільного розбору

```
## Підсумок розбору · [дата]
Розібрано N з M нотаток.
- Задачі: [перелік]
- Делегувати: [Ім'я] · [тема] (текст доручення готовий)
- Ресерч: [тема] · фраза для запуску
- На зустріч: [тема] · [Ім'я, дата]
- Дозріває: [кількість]
- Архів: [кількість]
Лишилось: [кількість], наступний розбір: скажіть «продовжимо розбір нотаток».
```

Далі розділ «Що можу зробити зараз» за `references/output-conventions.md`, розділ 3, і «Покриття й обмеження», якщо щось було недоступно.

## Приклад (скорочений)

Назви умовні. Усі збіги з реальними компаніями випадкові.

```markdown
[3 з 7] · Бонус за оборотність запасів · 08.10.2026 · склад, [Ім'я]
Суть: «Платити начальнику складу бонус за скорочення днів запасу. Обсяг відвантаження в бонусі не враховувати».
Пропоную: делегувати [Ім'я], фінансовому директору: порахувати ефект на оборотний капітал.
Чому: у вересневому P&L запаси зросли на 18% при падінні продажів на 4% [P&L_09_2026_v3.xlsx, «Баланс», C14].

Червона команда:
1. Проти: бонус за дні запасу штовхає до дефіциту в сезон.
2. Прихована вартість: облік днів запасу по SKU в ERP зараз ручний.
3. Опір: відділ продажів, якщо зростуть відмови клієнтам.
4. Має бути правдою: рівень сервісу не падає нижче 95%.
5. Тест: два тижні рахувати дні запасу і відмови по 20 ключових SKU.

Ваше рішення: «так», «пізніше», «архів» чи інше.
```

Користувач: «Так, делегуй, але після тесту».

```markdown
Статус: делегувати · наступний крок: тест 2 тижні, потім розрахунок.
ЧЕРНЕТКА доручення [Ім'я]: «[Ім'я], прошу протягом двох тижнів, до 29.10, рахувати дні запасу і відмови клієнтам по 20 ключових SKU. Результат: таблиця по тижнях і оцінка, як бонус за оборотність вплинув би на оборотний капітал. Доповісти на нараді 30.10».
Надіслати? Скажіть: «Надішли доручення [Ім'я]».
```

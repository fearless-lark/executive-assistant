# AI-асистент керівника

Матеріали практичного воркшопу для керівників: готові сценарії, повний промпт першого брифу та скіли для подальшої роботи.

**Сайт:** https://ai-executive-assistant.pages.dev/

Асистент готує бриф дня з аналізом нових документів (зранку план на день, пізніше що відбулось і що лишилось), розбирає надиктовані нотатки, складає огляди тижня і місяця, готує глибокі дослідження і тижневий радар. Усі скіли мають спільні правила безпеки: чужий текст вважається даними, а зовнішні дії виконуються лише після вашого підтвердження.

## Як проходимо воркшоп

Сайт: Головна → 1. Підключення → 2. Сценарії → 3. Розклад → 4. Скіли → 5. Deep Research → 6. Нотатки → 7. Телефон і голос, далі Безпека, Для компанії, Про нас. Бриф запускаємо повним промптом зі сторінки «Сценарії» і ставимо на розклад, потім встановлюємо скіли; хто не може встановити, працює промптами.

Сторінку «Сценарії» (`docs/scenarios/index.md`) і таблицю команд для сторінки «Скіли» (`docs/_snippets/skills-commands.md`) генерує `python3 scripts/build-scenarios-page.py` з `prompts/*.md`. Опис кожного сценарію лежить у `docs/_snippets/scenarios/<скіл>.md`. Після зміни промптів чи описів перезапустіть скрипт; `--check` перевіряє, що сторінка актуальна.

Встановлення пакета описано на сайті в розділі «Скіли». Спосіб залежить від платформи й прав робочого простору. Скіл не надає доступу до джерел.

## Скіли

| Скіл | Що робить |
|---|---|
| `exec-daily-brief` | Бриф дня з автоматичним аналізом документів: зранку план на день, пізніше що відбулось і що лишилось |
| `exec-meeting-prep` | Глибока підготовка до однієї зустрічі: учасники, минулі домовленості з джерел, питання, ваша межа |
| `exec-document-analysis` | Аналіз P&L, договору, пропозиції, звіту; аркуші перевірки формул, прогнозу і сценаріїв у самому файлі за вашим «так» |
| `notes-triage` | Щоденний розбір надиктованих нотаток; статус живе в заголовку кожної нотатки |
| `notes-assistant` | Робота з нотатками в розмові |
| `exec-review` | Огляд періоду: час, увага, віддача та перерозподіл зусиль |
| `exec-research` | ТЗ для Deep Research, рівні «Стандарт» і «Максимум», звірка звітів |
| `exec-radar` | Тижневий радар регуляторики, конкурентів і згадок |
| `exec-family-week` | План тижня для родини і помічника без ділових деталей |

## Структура

```
.claude-plugin/   маніфести маркетплейсу і плагіна
skills/           скіли (кожен у своїй теці з SKILL.md і references/)
prompts/          кожен скіл як один повний промпт для копіювання
shared/           спільні блоки: безпека, контекст із даних, формат виводу, заголовок нотатки
templates/        готові тексти регулярних задач
scripts/          службові скрипти
tests/            тести скілів
docs/             сайт (MkDocs Material)
overrides/        шаблони теми сайту
```

Локальна збірка сайту:

```
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Сайт розгортається на GitHub Pages автоматично після push у `main`.

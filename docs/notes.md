# Нотатки

Нотатка це все, що не можна забути. Ви записуєте думку текстом або голосом. Асистент розбирає нотатки і перетворює їх на задачі, нагадування й листи. Нотатки лишаються в Apple Notes, переносити нічого не треба.

## Як записувати

- **iPhone:** команда **Capture note** у застосунку «Команди»: Dictate Text (українська) → Create Note у папку «Вхідні думки». Запуск кнопкою дії, дотиком ззаду або «Hey Siri, Capture note». Siri не знає української, тому назва англійською.
- **Mac:** Параметри системи → Клавіатура → **Диктування**, додайте українську.
- **Android:** icloud.com/notes у браузері або Google Doc «Нотатки — вхідні».

## Папки-статуси

Нові думки потрапляють у папку «Вхідні думки». Після розбору асистент переносить нотатку в папку-статус:

| Папка | Для чого |
|---|---|
| 00 Вхідні | бракує даних для рішення |
| 01 До дії | ваші задачі й погоджені доручення |
| 02 Ідеї | гіпотези, питання, майбутні дослідження |
| 03 На зустріч | що обговорити на конкретній зустрічі |
| 04 Очікування | чию відповідь ви чекаєте |
| 05 Архів | закрите за вашим рішенням |

## Що ви побачите

Після першої команди кожна нотатка отримує п'ять рядків зверху: заголовок, кого стосується, горизонт, статус, створені дії. Ваш текст під ними не змінюється. Асистент покаже, які думки пов'язані з сьогоднішніми зустрічами і які теми повертаються.

Після другої команди він покаже задачу й чернетку і спитає підтвердження. Без вашого «так» нічого не створює і не надсилає.

## Де це працює

| Де | Apple Notes | Що робити |
|---|---|---|
| ChatGPT для Mac, режим Work | Так | Застосунок відкритий, Mac увімкнений |
| Claude Desktop на Mac | Так | Застосунок відкритий, Mac увімкнений |
| ChatGPT чи Claude у браузері | Ні | Ведіть нотатки в OneNote, Google Doc чи Notion і підключіть їх як джерело |
| Телефон | Лише запис | Команда «Capture note», розбір на Mac |

Щоденний розбір о 09:30 з Apple Notes працює лише тоді, коли Mac увімкнений, а застосунок відкритий. Нотатки в OneNote чи Google Doc розбираються в хмарі, навіть коли ноутбук закритий.

Так само асистент готує тиждень для родини: де ви будете, коли не на зв'язку, де потрібен водій. Промпт у [Сценаріях](scenarios/index.md#exec-family-week).

Щодня ваші надиктовані думки стають задачами, чернетками й нагадуваннями. Ідеї до найближчих зустрічей повертаються до вас вчасно.

**Коли:** щодня о 09:30 або будь-коли на запит<br>
**Зі скілом:** `Оброби нові нотатки`

#### Що в розборі

| Розділ | Що там |
|---|---|
| **Головне** | Три рядки. Першим: ідея до сьогоднішньої зустрічі, обіцянка зі строком сьогодні чи суперечність |
| **⚠️ Підозрілий вміст** | Лише коли текст у нотатці намагався керувати асистентом. Див. [Безпека](../security.md) |
| **До сьогоднішніх зустрічей** | «До зустрічі з [Ім'я] о 14:00 ви думали про…» і одне питання, яке варто поставити |
| **Дії** | Що зробити, хто виконує, строк, що вже підготовлено |
| **Нові ідеї** | Заголовок, кого стосується, горизонт, з якої нотатки |
| **Теми, що повертаються** | Тема з кількох нотаток: проблема, варіанти з ваших же слів, що треба дізнатися |
| **Суперечності** | Нова думка проти вашого попереднього рішення чи доручення. Обидві цитати з датами |
| **Обіцянки з нотаток** | «Пообіцяв», «домовились, що я…»: кому, що, строк, чи виконано за поштою |
| **Покриття і підпис** | Яку папку переглянуто, скільки нотаток, що не вдалося оновити і чому |

#### Як це працює

1. Асистент бере нові й змінені нотатки з папки «Вхідні думки».
2. Відділяє ваші слова від вставленого тексту: пересланого листа, фрагмента сайту, слайда. Дії бере лише з ваших слів.
3. Визначає тип: дія, ідея чи змішана. Сумнівне вважає ідеєю.
4. Звіряє з календарем, поштою і CRM: чи вже зроблено, чи стосується найближчих зустрічей.

Кожна нотатка отримує п'ять рядків зверху: заголовок, кого стосується, горизонт, статус, створені дії. Ваш текст під ними не змінюється. Нотатку з фото, вкладенням, таблицею чи чек-листом асистент не редагує, лише показує в результаті. Якщо в задачі сказано розкласти нотатки по папках, асистент переносить кожну в папку-статус і перевіряє, що вона там. Папки описано в розділі [Нотатки](../notes.md).

#### Що стає з дією

| Дія в нотатці | Що робить асистент |
|---|---|
| **Зробити самому** | Нагадування або подія у вашому календарі без запрошених |
| **Написати комусь** | Текст чернетки листа в результаті |
| **Доручити іншій людині** | Готовий текст доручення. Надсилаєте ви |
| **Зустрітися** | Прив'язка до зустрічі в календарі. Зустріч із запрошеними сам не створює |
| **Дослідити** | Фраза для запуску [Deep Research](../research.md) |

#### Як запустити

1. Натисніть **Скопіювати промпт** вгорі і вставте текст у новий чат у застосунку ChatGPT для Mac (режим Work) чи в Claude Desktop.
2. Надішліть.

Встановили [скіли](../skills.md): замість промпту достатньо команди «Оброби нові нотатки».

Apple Notes бачать лише застосунки на Mac: ChatGPT (режим Work) і Claude Desktop. Для щоденного розбору о 09:30 Mac має бути увімкнений, а застосунок відкритий. Папка називається інакше, ніж «Вхідні думки»: допишіть «Папка: [назва]». Розбір нічого не надсилає і не видаляє. Між запусками нічого не зберігається: стан нотатки видно з її папки і службових рядків.

# Для компанії

Таку систему можна зробити для будь-кого, хто працює за комп'ютером. Агент готує, людина перевіряє і відповідає.

## Хто ще може так працювати

- **Фінанси:** звірка платежів і дебіторки, пояснення відхилень з посиланням на рядок.
- **HR:** перший відбір резюме, графік співбесід, відповіді кандидатам.
- **Маркетинг і веб:** огляд конкурентів, тексти, перевірка сайту.
- **ІТ і розробка:** код за описом задачі, розбір інцидентів, документація.
- **Логістика і продажі:** строки й рахунки перевізників, досьє клієнта перед дзвінком.

## Як впроваджувати

| Крок | Що робите | Хто |
|---|---|---|
| 0. Вручну | Промпт у чаті на демо-даних або на кількох своїх файлах. Перевіряєте кожен висновок | Ви |
| 1. Регулярна задача | Повний текст промпту в задачі за розкладом. Скіли не потрібні | Ви |
| 2. Скіли для команди | ІТ вмикає скіли й конектори для групи людей. Один репозиторій, однакові правила безпеки | ІТ |

Переходьте на наступний крок, коли результат попереднього ви справді читаєте. Почніть з двох-трьох людей.

## Лист для ІТ {#it-letter}

=== "ChatGPT"

    ```text
    Тема: Асистент керівника в ChatGPT: що ввімкнути

    Прошу підготувати робоче середовище в ChatGPT.

    1. Тариф: ChatGPT Business або Enterprise. Потрібен DPA, навчання на наших даних вимкнене.
    2. Застосунки: Outlook Email, Outlook Calendar, SharePoint, Microsoft Teams, CRM. Для Enterprise увімкнути в Admin → Plugins. Для Microsoft 365 потрібна згода глобального адміністратора в Entra.
    3. Спершу лише читання. Дії на запис (надсилання листів, зміни в календарі) не вмикати до окремого рішення.
    4. Скіли: Admin → Plugins → Import marketplace, репозиторій https://github.com/fearless-lark/executive-assistant, політика Installed для групи нижче.
    5. Регулярні задачі (Scheduled) і сповіщення дозволені.
    6. Зберігання: який строк зберігання чатів ставимо і хто з адміністраторів має доступ до чатів.

    Починаємо з групи: [імена]. Через місяць перевіряємо результат.
    ```

=== "Claude"

    ```text
    Тема: Асистент керівника в Claude: що ввімкнути

    Прошу підготувати робоче середовище в Claude.

    1. Тариф: Claude Team або Enterprise. Потрібен DPA, навчання на наших даних вимкнене.
    2. Конектор Microsoft 365 (пошта, календар, SharePoint, OneDrive, Teams) і CRM: Organization settings → Connectors. Для Microsoft 365 потрібна згода глобального адміністратора в Entra.
    3. Спершу лише читання. Інструменти запису не вмикати до окремого рішення. Підтвердження дій лишити ввімкненим.
    4. Скіли: Organization settings → Plugins & skills, увімкнути Skills і Code execution and file creation. Для синхронізації зробити приватну копію репозиторію https://github.com/fearless-lark/executive-assistant (Sync from GitHub).
    5. Хмарні регулярні задачі (бета для Team і Enterprise) увімкнути для групи нижче.
    6. Зберігання: який строк зберігання чатів ставимо і хто з адміністраторів має доступ до чатів.

    Починаємо з групи: [імена]. Через місяць перевіряємо результат.
    ```

## Обережно

- **Якість.** В одній компанії за кілька місяців стало стільки згенерованого тексту, що задачі й код ніхто не міг прочитати. Кожен результат має читати й перевіряти людина.
- **Доступи.** Агент працює з правами не ширшими, ніж у працівника. Почніть з читання.
- **Приватність.** Вирішіть, чи можуть дані виходити назовні. Якщо дані чутливі: закритий контур, власні моделі на власній інфраструктурі. Для більшості щоденних задач відкритих моделей вистачає. Чи вийде дешевше, залежить від обсягу. Це треба рахувати.

Тарифи, суди і регуляторика: [Безпека](security.md).

## Два рівні

**Базовий:** пошта, календар, CRM, документи. Його ви налаштували на воркшопі.

**Повний:** агент підключений до всіх систем компанії з правами працівника. Механічну роботу (внести, вивантажити, звести) робить агент, людина перевіряє. Людина не ходить у CRM чи ERP, щоб щось знайти й вивантажити.

Для повного рівня потрібен порядок у даних і системах. Облікова система без нормального доступу для агента (1С, BAS і подібні) гальмує. Переїзд на власну систему робить команда з архітектором. Така система має лише потрібні функції, і працівник змінює її без розробника.

## Часті питання

- **Скільки коштує?** Тариф на кожну людину плюс час на налаштування.
- **Хто налаштовує?** ІТ разом з власником процесу.
- **Microsoft 365?** Підключення є в ChatGPT і в Claude. Потрібен адміністратор.

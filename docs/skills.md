# Скіли

Скіл це той самий сценарій, збережений у вашому ChatGPT чи Claude. Замість довгого промпту ви пишете коротку команду. Результат той самий.

| | Промпт | Скіл |
|---|---|---|
| Як запустити | Скопіювати й вставити в чат | Написати команду, наприклад «Бриф дня» |
| Що встановити | Нічого | Один раз, усі дев'ять сценаріїв разом |
| Коли брати | Перший запуск, будь-який тариф | Щоденна робота |

Почніть із промпту. Коли сценарій прижився, встановіть скіли.

!!! do "Що зробити зараз"

    === "ChatGPT"

        Скіли є на тарифах Business і Enterprise. Встановлює адміністратор робочого простору:

        1. Admin → **Plugins** → **Import marketplace**.
        2. Вставте адресу `https://github.com/fearless-lark/executive-assistant`.
        3. Політика встановлення: **Installed** для потрібних людей.

        Перевірте: бічна панель → **Plugins** → вкладка **Skills**. На особистих тарифах працюйте промптами.

    === "Claude"

        1. Customize → **Plugins** → Add → **Add marketplace**.
        2. Вставте адресу `https://github.com/fearless-lark/executive-assistant` і встановіть плагін **executive-assistant**.
        3. Перевірте: Customize → **Skills** або наберіть `/` у полі чату. Напишіть «Бриф дня».

    Не вийшло встановити: беріть промпт зі [Сценаріїв](scenarios/index.md). Результат той самий.
